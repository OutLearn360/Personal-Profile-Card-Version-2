## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/OutLearn360/Personal-Profile-Card-Version-2
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Start the project

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code if you have it installed.

## HTML Structure

The HTML creates the main profile card and organizes the content into sections for the profile information, statistics, action buttons, and social links.

The profile image is loaded from:

```text
images/profile-image.jpg
```

Make sure this image exists in the correct folder when running the project.

## CSS Features

The card uses a centered layout with a responsive maximum width, rounded corners, padding, and a subtle box shadow.

The statistics section uses Flexbox to arrange the three statistics horizontally.

The action buttons also use Flexbox and change to a vertical layout on smaller screens.

The project includes hover effects for:

* Primary button
* Secondary button
* Social links

## Responsive Design

The project includes a media query for screens smaller than `400px`.

On smaller screens:

* The profile card uses less padding
* The avatar becomes smaller
* The action buttons stack vertically

This helps the profile card remain usable on smaller devices.
